Arduino Nano Complete Pin Reference

A comprehensive engineering reference for the classic Arduino Nano based on the ATmega328P microcontroller. Covers digital I/O, analog inputs, PWM, UART, SPI, I²C, interrupts, timers, ADC, power, reset and bootloader behavior.

ATmega328P 5V 16 MHz 14 DIGITAL 8 ANALOG 6 PWM UART SPI I²C

Reference Scope

Important: This page documents the classic Arduino Nano based on the ATmega328P running at 5V / 16 MHz. It does not describe the Nano Every, Nano 33 IoT, Nano 33 BLE, Nano RP2040 Connect, Nano ESP32 or other Nano-family boards. Those boards should have separate canonical entries.

The ATmega328P contains a 10-bit successive-approximation ADC. The classic Nano exposes analog inputs A0 through A7.

Important: A6 and A7 are analog-only inputs on the classic Nano. Unlike A0–A5, they are not available as ordinary digital GPIO pins.

UART / Serial

The ATmega328P contains one hardware USART. On the Arduino Nano it is connected to:

D0 / RX USART Receive
D1 / TX USART Transmit 
Arduino Nano

D0 / RX  ← Serial data into MCU

D1 / TX  → Serial data from MCU
Serial debugging warning: D0 and D1 are shared with the Nano's USB/serial interface. Attaching another UART device to these pins while using USB serial can cause conflicts.

ATmega328P Timers

Timer Width PWM Pins Common Arduino Functions
Timer0 8-bit D5 / D6 millis(), micros(), delay()

Timer conflicts: Libraries that directly configure hardware timers can interfere with Arduino functions or other libraries using the same timer. This is especially important when using Servo, tone generation, motor-control libraries and custom interrupt-driven timing.

ADC Reference

  • Resolution: 10-bit
  • Numeric range: 0–1023
  • Reference: configurable through the ADC reference system
  • Default Arduino reference: typically the board's Vcc
  • External reference available through AREF 
int value = analogRead(A0);
Analog voltage warning: Do not interpret the ADC value as a universal voltage without accounting for the selected reference voltage, ADC behavior and the actual board configuration.

AREF

AREF is the external analog reference input for the ATmega328P ADC.

AREF External ADC reference
Never drive AREF incorrectly. The analog reference configuration must match the voltage supplied to the AREF pin and the reference mode selected by the firmware.

RESET

Pulling RESET low resets the ATmega328P. The Arduino Nano also uses reset behavior during programming through its USB-to-serial interface.

Built-In LED

The classic Arduino Nano development board normally connects its onboard LED to D13. 

#define LED_PIN 13

void setup() {

  pinMode(
    LED_PIN,
    OUTPUT
  );

}

void loop() {

  digitalWrite(
    LED_PIN,
    HIGH
  );

  delay(500);

  digitalWrite(
    LED_PIN,
    LOW
  );

  delay(500);
}
Because D13 is also the SPI clock pin, using the onboard LED can affect SPI-related signaling or vice versa. Consider this when using SPI peripherals.

Arduino Nano Engineering Rules

  1. D0 and D1 are the hardware UART. Avoid using them for ordinary peripherals when USB serial communication is required.
  2. A4 and A5 are the hardware I²C pins. They can also function as digital GPIO.
  3. D10–D13 are the hardware SPI pins. D10 is SS, D11 is MOSI, D12 is MISO and D13 is SCK.
  4. A6 and A7 are analog-only. They cannot be used as normal digital GPIO.
  5. PWM pins consume hardware timer resources. Timer-dependent libraries can conflict with one another.
  6. D13 normally drives the onboard LED. It is also SPI SCK.
  7. AREF must be treated as an analog reference connection. Do not arbitrarily drive it.
  8. Check voltage compatibility. Classic Nano logic is 5V, while many modern peripherals are designed around 3.3V logic.
  9. Do not exceed GPIO current limits. LEDs, motors, relays and other loads should normally use appropriate driver circuitry.
  10. Distinguish the Nano board from the ATmega328P itself. USB interface, regulator, power routing and headers are board-level characteristics.
